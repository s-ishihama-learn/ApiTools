## 🖼️ service-formatter

### 概要

**service-formatter** は、WebブラウザからXMLやHTMLを指定して、改行やインデントで書式を整形するAPIです。

### 機能

* XMLやHTMLをテキストまたはファイルで指定する。
* 「フォーマット実行」または「整形してダウンロード」ボタンで、変換処理を実行
* 変換結果がブラウザ上に表示またはファイルダウンロードされる

### 用途

* XMLやHTMLの書式を整えたい場合。
* 改行されていないXMLやHTMLの書式を整え見やすくする場合。
